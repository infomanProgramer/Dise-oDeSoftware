# Modelado de Dominio

La consigna es simple ***Evitar que la logica empresarial este esparcida por todos lados***

### Problematica

Muchos desarrolladores comienzan a construir un esquema de base de datos, con el modelo de objetos tratado como una idea de último momento. Aqui es donde todo empieza a salir mal. En su lugar el comportamiento debe ser lo primero e impulsar nuestros requisitos de almacenamiento.

### ¿Qué es un modelo de dominio?

Desde ahora en adelante, la logica empresarial va a estar contenida en la capa de modelo de dominio.

> Capa de logica empresarial = Modelo de Dominio

El dominio podria ser:

- Compras
- Adquisiciones
- Diseño de productos
- Logistica
- Entrega

Un modelo es un mapa de un proceso o fenomeno que captura una propiedad útil. El modelo de dominio es el mapa mental que los empresarios tienen de sus negocios.
